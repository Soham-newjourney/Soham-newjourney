## 👋 About this profile

This is my **collab account** — separate from my main profile, which I keep for solo/personal work. Everything here is for **team projects, hackathons, and stuff built together**.

I bring a **MERN + ML background** to a team: comfortable building the full-stack pieces (React, Node, Express, MongoDB) as well as the data/ML side (Python, scikit-learn, pandas). I like understanding how things work under the hood, so I'm usually the one asking "wait, why does this work?" in the group chat.
